# Backlog — 나중에 할 일

**earn-flow**에서 지금 당장 하지 않지만, 잊지 않기 위해 모아 두는 작업 목록입니다.

## 사용법

1. 새 항목 → `LATER.md` 해당 섹션에 한 줄 추가 (우선순위·담당·상태 표기)
2. 착수 시 → `상태`를 `🔄 진행중`으로 바꾸고, 완료 시 `✅ 완료` + 날짜
3. Lovable 라운드 전 → `rounds/` 승인 플랜 + [`PROMPT_HEADER.md`](../lovable/PROMPT_HEADER.md) 복붙
4. Cursor 세션 전 → **Cursor** / **Supabase** 섹션 + `LATER.md` 확인

## SSOT 관계

- **지금 해야 할 스택 규칙** → `docs/TECH_STACK.md` (고정, 변경 시에만)
- **나중에 할 개선·확장** → 이 폴더 (`docs/backlog/`)
- **Lovable 한 라운드 작업** → `docs/lovable/` + Lovable `plan.md`

이 폴더는 “규칙”이 아니라 **일정·기억 보조**입니다. TECH_STACK과 충돌하면 TECH_STACK이 이깁니다.
